# FX Verse Premium

An independent Android demo with a premium dark social-feed UI, animated story rings, motion graphics, like interactions, and bottom navigation.

## Build the APK
1. Open the **Actions** tab.
2. Select **Build FX Verse APK**.
3. Tap **Run workflow** on the `main` branch.
4. When the run succeeds, download the **FX-Verse-debug-APK** artifact.

This is a UI prototype. Authentication, live messaging, posting, and backend/database features are not connected yet.
